Challenge: Level 1 Challenge 1 - Surface Area

PROBLEM DESCRIPTION:
Selvan was playing with an object of random size for stress relief. Selvan knows the Length, Width, and Height of the object. But he would like to know the surface area of the object he is playing with. Can you help him in finding it?

Functional Description: Surface area of the Object = 2 x [width x length + length x height + height x width]

CONSTRAINTS:
* 1 <= length <= 20
* 1 <= width <= 20
* 1 <= height <= 20

INPUT FORMAT:
* First Line: Length of the object in Integer.
* Second Line: Width of the object in Integer.
* Third Line: Height of the object in Integer.

OUTPUT FORMAT:
* Print a single integer value representing the surface area of the object.

SAMPLE TEST CASES:
Test Case 1
Input: 3 2 3
Expected Output: 42

Test Case 2
Input: 3 7 4
Expected Output: 122
