# 100 Days of Code Challenge 🚀

Welcome to my **100 Days of Code** journey! In this repository, I am documenting my daily progress as I commit to writing code and solving logical programming challenges every day for 100 consecutive days.

## 📁 Repository Structure & Documentation
The repository is organized chronologically by day. Each day has its own dedicated folder containing all the necessary files for that specific challenge. 

Inside each daily folder (e.g., `Day1/`, `Day2/`), you will find two main files:
* **The Problem Statement (`.txt` file):** This text file contains the complete details of the daily challenge. It includes the full problem description, mathematical constraints, input/output formatting requirements, and sample test cases. 
* **The Solution (`.c` file):** This file contains my coded solution to the problem, written in C.

## 🎯 Goals for this Challenge
* Code consistently every day for the next 100 days.
* Master the fundamentals and advanced concepts of C programming.
* Enhance my algorithmic thinking and problem-solving skills.
* Maintain a public log to hold myself accountable and track my growth.

## 🛠️ Tech Stack
* **Language:** C
* **Platform:** eLab / Local Environment
